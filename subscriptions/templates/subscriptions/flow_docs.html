Frontend Subscription & Sign-Up Flow

This document explains the step-by-step flow for integrating Razorpay plan purchasing with the user sign-up and login process.

Overview: We use an asynchronous flow. The user pays before their account is fully registered. The backend securely links their payment to their email/phone so that when they finally complete sign-up, the paid plan is automatically assigned instead of the free trial.

Flow Steps

1

User Selects a Plan

On the Pricing page, the user clicks "Subscribe" on the Basic plan. You prompt them for their email or phone number (this is required to link the payment before they sign up).

2

Create Razorpay Order (Backend Call)

Call the backend to generate a secure Razorpay Order ID. Do not generate the order strictly on the frontend.

POST /api/subscriptions/create-order/

Request Body: 
{
    "plan_id": 2, // The ID of the Basic Plan
    "email": "user@example.com" // OR "phone_number": "9876543210"
}
Response: 
{
    "error": false,
    "order_id": "order_Hlk...",
    "amount": 99900,
    "currency": "INR",
    "key": "rzp_test_..." // Your Razorpay Key ID
}
3

Initialize Razorpay Checkout

Using the details from Step 2, open the Razorpay Checkout modal.

const options = {
    "key": response.data.key,
    "amount": response.data.amount,
    "currency": response.data.currency,
    "name": "Your Company Name",
    "description": "Basic Plan Subscription",
    "order_id": response.data.order_id,
    "handler": function (response){
        // Proceed to Step 4 on success
        verifyPayment(response);
    },
    "prefill": {
        "email": "user@example.com"
    }
};
const rzp1 = new Razorpay(options);
rzp1.open();
4

Verify Payment (Backend Call)

After a successful payment, send the Razorpay response to the backend for cryptographic verification.

POST /api/subscriptions/verify-payment/

Request Body: 
{
    "razorpay_order_id": "order_Hlk...",
    "razorpay_payment_id": "pay_Hlk...",
    "razorpay_signature": "signature_hash..."
}

Success! The backend now knows this email/phone has a paid plan waiting for them.

5

Redirect to Sign-Up

Redirect the user to your Sign-Up / Registration page. Crucial: Pre-fill the email or phone number they just used to pay.

6

Complete Registration

Call the standard sign-up endpoint just like you do for the Free plan.

POST /v1/auth/company-users/

Request Body: 
{
    "company_name": "My Store",
    "email": "user@example.com", // MUST match the payment email
    "phone_number": "9876543210",
    "number_of_outlets": 1,
    "number_of_employees": 5
}

Behind the scenes: The backend automatically detects the successful payment tied to this email, skips the 15-day Free Trial, assigns the Basic Plan, and sets the valid validity date based on the plan tenure!

7

Auto-Login & Redirect to Dashboard

Using the credentials or token from the successful sign-up response, log the user in, and redirect them to their main Dashboard view. They are now fully subscribed and ready to go!
